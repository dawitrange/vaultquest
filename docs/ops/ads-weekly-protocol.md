# Weekly ads test protocol — VaultQuest

**Owner override:** 2026-08-16 Ethio. Weekly tests are in force. Aggressive spend for quick gains is allowed toward the $40k car. Earn-live work runs in parallel. Banned claims still apply.

Live destination is always **https://www.vaultquest.io** (home, `/how-it-works`, or `/earn`). Never send paid traffic only to a raw partner wall.

## Cadence

| When | Do |
|------|----|
| Monday | Recut cells. Kill losers. Scale winners. Write the week’s cost / lift / kill in `docs/ops/weekly-*.md` if that file exists, else the overnight debrief. |
| Mid-week | One creative refresh from competitor Facebook playbook (`docs/ops/competitor-facebook-playbook.md`). |
| Friday | Unit-econ check: CAC vs expected first-earn yield. Recommend scale / hold / kill. |

## Cell design

2–4 cells at a time. One change per cell (angle **or** creative **or** audience).

Required UTM on every URL:

`https://www.vaultquest.io/?utm_source=meta|youtube&utm_medium=paid&utm_campaign=<week>&utm_content=<cell>`

## Default caps (until Ethio changes them)

- Meta: **$150/day**
- YouTube: **$50/day**
- Kill a cell after about **$40** with no signup, or 3 days of CAC above expected first-earn yield, or a policy reject for claims.

## Claims (ads and organic)

Allowed: complete partner quests, earn Vault points, redeem Steam credit/keys subject to stock and balance, fair giveaways, we earn when you complete offers, honest time ranges.

Banned: generators, working codes, no survey, guaranteed $, Steam passwords, fake urgency counters, implying we are Valve.

## Kill / scale

| Signal | Action |
|--------|--------|
| Signup CAC well under expected first-earn yield for 2 days | Scale that cell. Pause the rest. |
| Spend with no signups | Kill. Replace creative from the Facebook playbook. |
| Signups but no `/earn` click | Fix the landing PR before more spend. |
| Earn clicks but no VP credit | Stop scaling ads. Fix postback / partner wall. |
| Policy reject | Rewrite to compliance. Do not sneak the banned claim back. |
