## Adopt

1. CTA always to **vaultquest.io** (UTM / channel path). Never a raw CPX / AdGate wall URL in the post.
2. Say the work out loud. Quests → Vault Points → Steam credit. No “no survey” lie.
3. Public codes in the caption if we ever have a real one. Never DM / Telegram / comment-to-unlock.
4. Leave real comments up, including complaints. Reply with a ticket path.
5. Bounded giveaway with published rules if we ever run one. Live Steam price ≤ funds actually received.
6. Guess / debate hooks beat offer dumps. The offer rides in the last line.
7. Honest thin engagement over fake proof. No “$X paid today” tickers, no fake testimonials, no “X people earning now.”
