## 1. Competitive video teardown

### What wins search + suggested (legit GPT / earn styles)

| Pattern | Examples / signals | Why it works | Vaultquest copy |
|--------|--------------------|--------------|-----------------|
| **Skeptic-busting title** | “How to Get FREE Steam Balance in 2026 (It Actually Works)” | Matches “free Steam” intent; “actually works / legit” filters scam fatigue | Use year + “honest / legit / no generator” — never “instant $50” |
| **Result-first hook (0–8s)** | Show Steam Wallet bump, gift card amount, or points → redeem UI | Viewers stay if they see the *outcome* before the lecture | Show Vault points → Steam redeem mock (label as demo if not live) |
| **Walkthrough structure** | Freecash / Freeward / Swagbucks style: signup → pick offer → complete → redeem | Feels teachable; chapters boost SEO | Same 4 beats, but hub = Vaultquest |
| **Honest time talk** | Freeward blog: 2–3h possible for Tier-1 game offers; most take longer | Retention + trust; cuts rage comments | State ranges; never guarantee $ amounts or speed |
| **Anti-scam contrast** | “Generators are fake — here’s the real path” | Differentiates from malware/keygen videos YouTube still surfaces | Explicit: no generators, no Steam passwords |
| **Single primary CTA** | “Link in description” early + late | Freecash CPA funnels convert on one clear action | CTA = Vaultquest (or waitlist), not raw partner only |
| **Thumb: 2–3 words + Steam visual** | FREE STEAM / LEGIT / NO GEN | Mobile CTR; title carries SEO | Big Steam-adjacent art + “HONEST PATH” or “EARN → VAULT” |

### Length norms

| Format | Typical length | When to use |
|--------|----------------|-------------|
| **Hook Short / teaser** | 30–60s | Later; not Video 01 |
| **First / proof walkthrough** | **90–180s** | **Recommended for Video 01** — low production, high clarity |
| **Deep Freecash-style tutorial** | 8–20 min | After site live + real cashout proof |
| **Scam generator spam** | 5–12 min of fake UI | **Never** |

**Video 01 target:** **~2:00–2:30** spoken (~130–160 words/min → script ~280–360 words). Cap at ~5 min only if you add real screen time for signup + one offer pick.

### Thumbnail patterns

| Copy | Avoid |
|------|--------|
| High-contrast Steam wallet / gift-card visual | Fake “CODE ACCEPTED” / progress-bar generators |
| 2–3 huge words (Bebas/Impact-style condensed) | Paragraph of text; title duplicated on thumb |
| Face optional: mild surprise/confidence helps CTR | Rage-face + “$100 FREE!!!” scam energy |
| Brand mark small but readable (Vaultquest) | Pure purple neon crypto casino look |
| Leave bottom-right clear (timestamp) | Cluttered pill stacks / emoji spam |

### Title / hook language that converts (legit)

- “How to earn free Steam…” / “Steam Wallet in 2026…”
- “Legit” / “honest” / “actually works”
- “No generator” / “what’s real vs scam”
- Year in title for freshness (`2026`)

### Title / hook language to avoid (banned for Vaultquest)

- “Working codes 2026” / “unlimited free Steam”
- “No survey / no download” if surveys/offers exist
- “Guaranteed $50 in 5 minutes”
- Generators, hacks, “Steam cracked”
- Urgency fakes: “last 100 codes”

### CTA styles that work

1. **Early soft CTA (seconds 10–20):** “Link for Vaultquest is in the description.”
2. **Mid retention:** numbered steps on screen.
3. **Hard CTA near end (not last frame):** one ask — join / waitlist / start earning.
4. **Pinned comment:** repeats link + disclosure + “ask questions here.”
5. **End screen:** subscribe + next video (or channel trailer once live).

### Disclosure norms (do this)

- Spoken + description: “This video may include affiliate / partner links. We may earn when you sign up or complete offers.”
- If waitlist only: say so — “site launching; join the list.”
- Never coach VPN / multi-account / fraud.

### What to copy vs avoid (summary)

| Copy | Avoid |
|------|--------|
| Gamesbolt/Earnit quest → points → redeem framing | Fake generator UIs |
| Freecash funnel: YouTube → *our* site | Sending 100% traffic only to Freecash |
| Honest time + survey/offer reality | “No survey” lies |
| Anti-scam opener | Malware “free Steam key” download CTAs |
| Chapters + pinned link | Comment-disabled scam channels |
| Real (or clearly labeled demo) proof | Fake live “recently rewarded” ticks |

## 4. Budget proposals (YouTube)

Per `docs/08-budget.md`: propose cost / lift / kill; owner approves before spend. Prefer free until ROI clear.

| Proposal | Cost | Expected lift | Kill criteria |
|----------|------|---------------|---------------|
| **Canva Free / Photopea** for thumbs | $0 | Enough for Video 01 CTR test | — keep unless design quality blocks brand |
| **Canva Pro** (thumb + banner polish) | ~$15/mo | Faster brand-consistent thumbs; easy A/B exports | Cancel if <2 videos/mo or CTR never tested |
| **Thumbnail A/B** — YouTube native Test & Compare (3 thumbs) | $0 | +8–25% CTR possible on text/bg tests | Stop iterating if CTR <2% after 1k impressions *and* title is weak — fix title first |
| **Mild YouTube Boost / Promote** on Video 01 | **$20–50** test | Faster first 500–2k views to learn CTR/AVD | Kill if CPC high **and** AVD <40% or outbound CTR ~0; never boost before honest landing exists |
| **Reserve second boost** | $50–100 | Only if Video 01 AVD ≥45%, CTR ≥4%, link clicks happening | Do not scale until earn path or waitlist converts |
| **TubeBuddy / VidIQ free tier** | $0 | Tags + search ideas | Skip paid tiers until posting cadence ≥4/mo |
| **Mic upgrade** (USB) | $40–80 | Watch time if current audio is harsh | Only if comments/complaints about audio |

**Sequence:**

1. Rebrand + publish Video 01 organic (**$0**).  
2. Measure 72h: impressions, CTR, AVD, link clicks.  
3. If landing/waitlist live and CTR ≥ ~3.5–4% but reach is tiny → **$20–50** boost.  
4. Kill boost immediately if traffic is junk (no clicks, <30s AVD).

**Do not spend** marketing budget on YouTube ads until claims policy + a real destination (waitlist minimum) exist.
