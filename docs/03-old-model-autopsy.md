# Old model autopsy — freesteamcodes21 / ZaKai

## What it was

Weebly site (~2020) promising free Steam codes, funded by Freecash + PointsPrizes referrals, PayPal donations, Facebook group, and YouTube (ZaKai).

## Funnel (as operated)

1. Land on Weebly home (“free Steam codes”)
2. Email/name giveaway capture
3. Donate CTA and/or “support free” path
4. Code #1 → Freecash referral (skip ad → signup) → **Contact Us** claiming completion → manual agent email → code
5. Code #2 → PointsPrizes for higher value
6. Facebook community + YouTube subscribe side paths

## What scaled (keep the idea)

- Affiliate-funded rewards (you earn when users qualify)
- YouTube + Facebook as discovery
- Community for giveaways / updates
- Honest framing *if* rewritten: users do tasks; platform earns; rewards funded from that

## What failed (kill)

| Failure | Why it hurt |
|---------|-------------|
| “NO SURVEY OR DOWNLOAD” title while requiring surveys | Trust nuke; ad/partner bans |
| Manual contact-to-redeem | Unscalable, feels scammy, support hell |
| Thin proof (“PROOF WE ARE REAL” with little evidence) | Users bounce |
| Single/few affiliate links | Cap or death = dead business |
| gestyy shortlinks | Spam reputation |
| Weebly template / duplicate Home nav / typos | Amateur = scam signal |
| No in-house ledger | No points economy, no retention, no margin control |
| Journal unfinished | Incomplete product |

## Profit leaks

- Support time on every redeem
- Users drop at Contact step
- No postback → can’t verify completions reliably at scale
- Donation-dependent narrative vs productized earn path

## Migration rule for Vaultquest

Copy **affiliate-funded rewards + YT/community**. Replace fulfillment with **in-house points + redeem + scheduled giveaways**. Never revive contact-gated codes or generator claims.
